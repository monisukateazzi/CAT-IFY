# CAT-IFY
CATS ARE TAKING OVER THE WORLD!!! 🐈‍⬛

MONI HERE!! So I made a little Tampermonkey extension called CAT-IFY. Basically, whenever there's an image on a website, it'll automatically turn into a picture of a cute little cat.

# HOW TO INSTALL CAT-IFY 🐾
1. First, download the Tampermonkey extension on your computer.
2. Once it's installed, click the Tampermonkey logo and select Create a new script.
3. You'll see a template code. Feel free to delete everything there.
4. Open the "catify.user.js" file and copy all the code into your Tampermonkey editor.
5. Don't forget to hit Save!
6. Once saved, make sure the script is toggled ON.

AND VOILÀ!! YOUR INTERNET IS NOW 100% MORE CAT-IFIED. 🐈

# ⚠️ IF IT DOESN'T WORK:
# PLEASE MAKE SURE YOU'VE ENABLED ALLOW USER SCRIPTS IN YOUR TAMPERMONKEY EXTENSION SETTINGS!!

Happy cat-ifying!! :D
